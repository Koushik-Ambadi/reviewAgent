Planned workspace capabilities

These are deliberate next steps, not active controls. They extend the current run workspace after its evidence, build, and remediation foundations are stable.

Planned

Pull request and approvals

Create a governed handoff for manager approval, source-control changes, and auditable release decisions instead of exposing a premature Raise PR button.

Planned

Multi-run workspace

Compare review runs, modules, profiles, and trends across projects. Module and profile filters belong here rather than inside a single run.

Planned

Configurable profiles

Add validated project profiles and build adapters once profile selection, schema migration, and project ownership are defined.

Planned

Optional assisted intelligence

Keep deterministic classification first, then add opt-in model analysis for unknown failures with evidence, provenance, and provider-independent outputs.

Remediation

Suggested fixes

Choose a failed check or case to generate a suggestion.
